# 📱 IoT Connect Mobile Application

IoT Connect is a high-performance, real-time mobile dashboard built with React Native and Firebase. It provides multi-tenant IoT device management, environmental monitoring, and an automated subscription-based access control system.

## 🚀 Key Features

*   **Real-Time Telemetry**: Instant synchronization of temperature, humidity, and air quality (Gas/AQI) data.
*   **Multi-Tenant Architecture**: Secure client isolation—users only see devices assigned to their `clientId`.
*   **Effective Status Algorithm**: Automated access control based on subscription standing:
    *   **ACTIVE**: Full unrestricted hardware control.
    *   **ENDING SOON**: 7-day proactive renewal warning.
    *   **LOCKED**: Automated interaction blocking for unpaid or expired accounts.
*   **Device Hardening**: Hardware-level locking UI when `isPaid` status is false.
*   **Dynamic Dashboard**: Aggregated system health, sensor averages, and priority alerts.

## 🛠️ Tech Stack

*   **Framework**: React Native (Expo/Vanilla compatible)
*   **Navigation**: React Navigation (Native Stack + Bottom Tabs)
*   **Backend**: Firebase Firestore (Real-time Snapshot Listeners)
*   **Styling**: Premium Dark-Mode Glassmorphism Design System

## 📂 Firestore Database Schema

### 📊 `clients` (Root Collection)
| Field | Type | Description |
| :--- | :--- | :--- |
| `id` | `string` | UUID generated by Firestore. |
| `name` | `string` | Legal entity or contact name. |
| `subscription` | `map` | Contains `status`, `endDate`, `paymentStatus`, etc. |

### 🛠️ `devices` (Root Collection)
| Field | Type | Description |
| :--- | :--- | :--- |
| `id` | `string` | Hardware UUID. |
| `clientId` | `string` | Foreign Key to `clients.id`. |
| `status` | `string` | `active | inactive | error`. |
| `isPaid` | `boolean` | Real-time payment standing flag. |

### 🌡️ `telemetry` (Root Collection)
| Field | Type | Description |
| :--- | :--- | :--- |
| `deviceId` | `string` | Foreign Key to `devices.id`. |
| `temperature`| `number` | Degrees Celsius. |
| `humidity` | `number` | Percentage. |
| `gas` | `number` | Air Quality Index (AQI). |
| `timestamp` | `number` | Unix epoch. |

## 🚦 Getting Started

1.  **Clone the repository**
2.  **Install Dependencies**:
    ```bash
    npm install
    ```
3.  **Configure Firebase**:
    Update `Firebase.js` with your Firebase project credentials.
4.  **Run the application**:
    ```bash
    npm start
    ```

## 🔒 Security & Access Control

The app implements a **Dual-Layer Access Check**:
1.  **UI Layer**: Components check the `isPaid` boolean and `subscription.endDate` to grey out controls and show "Locked" overlays.
2.  **Data Layer**: It is recommended to implement Firebase Security Rules to prevent unauthorized data reads/writes based on the `clientId`.
